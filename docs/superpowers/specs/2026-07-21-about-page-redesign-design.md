# About ページ リデザイン設計書

## 背景・目的

現行の About ページ（`src/app/(main)/about/page.tsx`）は Unsplash のストック画像を多用しており、本文も一部意味の通らない仮テキストになっている。これを刷新し、

- 画像は一旦すべて撤去する（雰囲気セクションのみ、将来写真を差し込む前提のプレースホルダー枠を残す）
- タイトル・ヘッダー部分（`PageHeader` セクション：「ABOUT RUG CLUB」の大見出しと背景の大型半透明テキスト）はデザインを変更しない
- 実在するブランドコンセプト・オーナーへのヒアリング内容をもとにした本物のコピーに差し替える
- `https://sawataya.jp/` を参考に、スクロール連動の「動きのある」個性的なページにする
- 他のページ（Menu, Gallery, Access, News, Contact, Admin 等）には一切手を加えない

## 参考サイト調査結果（sawataya.jp）

技術調査により判明した構成：

- **GSAP + ScrollTrigger**（無料・MITライセンス）でスクロール連動アニメーションを実装
- **GSAP ScrollSmoother**（有料プラグイン）で慣性のある滑らかなスクロールを実現 → 本サイトでは無料の同等機能として **Lenis**（smooth-scroll ライブラリ）を採用する
- 基本要素（見出し・本文・画像）は「不透明度0→1 ＋ `translateY(20px)→0`」のフェード＋スライドインで出現。既存の `FadeIn.tsx`（IntersectionObserver ベース）と同じ考え方であり、大枠の演出はこれを踏襲・拡張する
- 大見出しは `mask-position` を使った **マスクワイプ演出**（カーテンが開くように文字が現れる）で強調されている
- 画像は SVG `clip-path` による有機的な切り抜き形状＋ `scale(1.2)→scale(1)` のズームアウトで出現する

### 本サイトでの採用方針

| 要素 | sawataya.jp | RUG CLUB About（本設計） |
|---|---|---|
| スクロール演出の基盤 | GSAP + ScrollTrigger | 同左（新規導入） |
| 慣性スクロール | ScrollSmoother（有料） | Lenis（無料）※任意・フェーズ2でも可 |
| 基本フェード | opacity+translateY | 既存 `FadeIn` を GSAP ScrollTrigger 版に置き換え、同じ見た目を維持 |
| 見出し演出 | mask-position ワイプ | 同様のマスクワイプを CSS + GSAP で実装 |
| 画像演出 | clip-path + zoom | 「雰囲気」セクションの写真プレースホルダーに同様の枠だけ用意（実写真は後日） |

## ページ構成

`PageHeader`（変更なし）の下に、以下の3セクションを配置する。他のセクション（Hero画像、MainConcept、Values、SplitArt、SplitCoffee、OwnerComment）はすべて削除する。

### セクション1：コンセプト（背景：クリーム `#F0E6D2`、文字：ネイビー `#1A2535`）

見出し：
```
身近に、
アートを感じる場所。
```

本文1（店名の由来・きっかけ）：
> 「将来カフェなんかできたらいいよなぁ」。中学のラグビー部の仲間と交わした、なにげないひとことが原点です。RUG CLUBという名前には、その頃の記憶が込められています。

本文2（アートとの関わり）：
> 学生時代から絵を描くことが好きで、美術を学び、かつては美術教師として教壇に立っていました。私にとってアートは特別なものではなく、日常の隣にあるもの。ふらりと立ち寄った古本屋で見つけた一冊の画集や、色褪せた雑誌の表紙。そんな些細な出会いが、今でも心を動かしてくれます。

### セクション2：雰囲気（背景：赤 `#EF4123`、文字：クリーム/白）

見出し：
```
吹き抜けの開放感と、
木の温もり。
```

- 本文なし。写真プレースホルダーのみ配置する（点線枠＋シマーアニメーション、"PHOTO AREA" 表示）。将来ここに実写真を差し込む。

### セクション3：こだわり・強み（背景：クリーム、文字：ネイビー）

見出し：
```
常に、
アートを感じられる場所。
```

本文（コーヒー×アートを組み合わせた理由／差別化ポイント）：
> ギャラリーカフェという業態は、そう珍しいものではありません。だからこそ気負うことなく、これまで培ってきたアートの知識を活かせる場所として、コーヒーとアートを組み合わせました。家具はひとつひとつ、自分たちの目で選んだ60年代からのヴィンテージ。店内には20点ほどの作品を展示し、料理を待つ時間はスマホではなくアートを眺めて過ごす、そんなひとときも大切にしています。

締めの一文（引用・イタリック調）：
> 「素敵な空間だった、また来たい」——そう思っていただけることが、なによりの喜びです。

## 技術設計

### 新規依存パッケージ

- `gsap`（ScrollTrigger を含む。コアライブラリと ScrollTrigger は無料）
- `lenis`（慣性スムーズスクロール。任意・優先度低）

### コンポーネント構成

```
src/app/(main)/about/page.tsx        … PageHeader（既存）+ 3セクションの呼び出し
src/app/(main)/about/_components/
  ConceptSection.tsx                 … セクション1
  AtmosphereSection.tsx              … セクション2（写真プレースホルダー含む）
  StrengthSection.tsx                … セクション3
  MaskRevealHeading.tsx              … マスクワイプ見出し用の共通クライアントコンポーネント（GSAP ScrollTrigger使用）
```

- `MaskRevealHeading` は `'use client'` コンポーネントとして、GSAP ScrollTrigger で該当要素が画面内に入ったタイミングで `clip-path` または `mask-position` をアニメーションさせ、文字が現れる演出を行う。既存の `FadeIn` はそのまま残し、本文パラグラフなど従来通りのフェード用途に引き続き使用する。
- 写真プレースホルダーは既存デザイン（シマーアニメーション）を CSS の `@keyframes` で実装し、追加ライブラリ不要とする。

### 影響範囲

- 変更するファイル：`src/app/(main)/about/page.tsx`、新規追加する `_components` 配下のファイル、`package.json`（GSAP/Lenis追加）
- 変更しないファイル：他の全ページ（Menu, Gallery, Access, News, Contact, Admin 配下）、`Header.tsx`、`Footer.tsx`

## テスト・確認方法

- ローカル開発サーバーでページを表示し、3セクションが正しい配色・文言で表示されることを確認
- スクロールに応じて見出し・本文がフェード/マスクワイプで出現することを確認
- モバイル幅（375px）・デスクトップ幅（1280px）両方でレイアウト崩れがないことを確認
- 他ページ（Menu, Gallery, Access 等）に影響がないことを確認（diff で About 以外に変更がないことを確認）

## 対象外（今回やらないこと）

- 建物（外観・2階貸しホール）・席数情報の掲載 → 今回は含めない
- 実写真の追加（プレースホルダーのみ）
- Lenis によるスムーズスクロールの実装は任意（GSAPのScrollTrigger演出を優先し、Lenisは時間があれば追加）
